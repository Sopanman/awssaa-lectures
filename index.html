全8本各 60-90分SAA-C03 対応
01

資料

W1 IAM 権限の決まり方
6つの実務シナリオでIAMを組み立てる。ロール、クロスアカウント、ExternalId、権限境界、SCP、評価ロジック。 W1 VPC と通信経路の設計
図で見るVPC。サブネットの入れ子、3つの関所、NAT Gateway、VPCエンドポイント、SGとNACLのシーケンス図、VPNとDirect Connect、Transit Gateway。 W2 EC2 とスケーリング設計
図で見るコンピューティング。インスタンスタイプとT系のクレジット、購入オプション、スポットの中断、配置グループ、ロードバランサー（ELB）三種、Auto Scaling、スケーリングポリシー、Lambdaの実行環境と同時実行、コンテナとECS・EKS・Fargate。各場面で初出の用語を正式名称つきで説明。 W3 S3 とストレージ選定
S3のストレージクラスとライフサイクル、アクセス制御と暗号化、EBS・EFS・FSxの使い分け。 W4 データベースの選び方
RDSのMulti-AZとリードレプリカ、Aurora、DynamoDBのキー設計とインデックス、ElastiCacheの使い分け。 W5 暗号化と脅威検知
KMSとエンベロープ暗号化、Secrets Manager と Parameter Store、WAF・GuardDuty・Inspector などの役割分担。 W5 疎結合と監視の設計
SQS・SNS・EventBridgeの使い分け、Step FunctionsとAPI Gateway、CloudWatchとCloudTrailの違い。 W9 コストの決まり方
購入オプションの選択、データ転送料金の原則、ストレージのコスト削減、Well-Architected Frameworkの6つの柱。

この資料の方針
